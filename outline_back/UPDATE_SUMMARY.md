# Course Outline Background Processing - Update Summary

## Overview
Updated the outline background processor to use the new `course_outlines` database table structure and generate structured JSON data instead of markdown.

## Changes Made

### 1. Database Model (`model.py`)
- **Old Structure**: Simple `Outline` table with `outline_content` TEXT field storing markdown
- **New Structure**: Comprehensive `course_outlines` table with:
  - `terminology_type` and `terminology_role` (Course/Subject, Lecturer/Teacher)
  - JSONB fields for dynamic data: `school_info_headers`, `lecture_info`, `course_objectives`, etc.
  - TEXT fields for descriptions: `course_description`, `course_delivery`
  - Metadata fields: `subject_name`, `class_name`, `academic_year`, `semester`
  - Status tracking: `status`, `version`, `last_auto_save`

### 2. Prompt Builder (`build_outline_prompt`)
**Before**: Requested markdown-formatted outline with sections like "Course Overview", "Curriculum Structure Summary", etc.

**After**: Requests **strict JSON format** with exact structure matching the API:
```json
{
  "terminology": {"type": "Course", "role": "Lecturer"},
  "schoolInfoHeaders": [...],
  "lectureInfo": {"left": [...], "right": [...]},
  "courseObjectives": [...],
  "courseDescription": "...",
  "learningOutcomes": [...],
  "courseDelivery": "...",
  "courseContent": [{"topic": "...", "activity": "..."}],
  "policies": [...]
}
```

**Key Features**:
- Auto-detects terminology (Course/Subject) based on `academic_level`
- Instructs AI to create 12-16 weeks of content
- Maps curriculum strands/substrands to weekly topics
- Generates context-appropriate policies and objectives

### 3. Storage Function (`store_outline_in_db`)
**Before**: Stored raw markdown string in `outline_content` field

**After**: 
1. **Parses JSON** response from AI
2. **Validates** required fields (with fallback defaults)
3. **Transforms** data to match database schema:
   - Extracts `terminology`, `schoolInfoHeaders`, `lectureInfo`, etc.
   - Adds week numbers to `courseContent` items
   - Maps `semester_name` → `academic_year`, `term` → `semester`
4. **Stores** in new structured format
5. **Logs** detailed statistics (objectives count, weeks count, etc.)

### 4. AI Configuration (`call_ai_for_outline`)
- Removed `responseMimeType: "application/json"` to allow plain text JSON
- Kept high token limit (65536) for comprehensive outlines
- Temperature: 0.5 for balanced creativity/consistency

## Data Flow

```
1. Teacher triggers outline generation
   ↓
2. Enqueue task (enqueue_outline.py)
   ↓
3. Worker picks up task (outline_worker.py)
   ↓
4. Fetch curriculum data from DB
   ↓
5. Build JSON-requesting prompt
   ↓
6. Call Vertex AI (Gemini 2.5 Flash)
   ↓
7. Parse JSON response
   ↓
8. Store in course_outlines table
   ↓
9. Frontend fetches via GET /api/teacher/course-outline
```

## API Integration

The background processor now generates data that perfectly matches the API endpoints:

### Read Endpoint
`GET /api/teacher/course-outline?subject_name=X&class_name=Y`
- Returns the structured outline generated by the background worker
- If no outline exists, returns empty template

### Save Endpoint
`POST /api/teacher/course-outline/save`
- Teachers can manually edit the AI-generated outline
- Updates are saved in the same format
